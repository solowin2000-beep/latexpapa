首页大图放这里 / HERO IMAGE
================================

把做好的图片放在这个文件夹，文件名必须是：

    hero.jpg    或    hero.png    或    hero.webp

（三个扩展名任选其一；如果放 webp，网站会直接用，体积最小）

图片要求：
  - 竖版 4:5，建议 1024 x 1280 像素（宽最少 1000px）
  - 内容不要太靠边，四边留一点空间（手机上会被裁掉边缘）
  - 建议 300KB - 900KB 之间

放好之后告诉我一声，我重新发布一次网站，首页右边那个
"Product photography" 占位框就会换成你的图片。

如果这个文件夹是空的，网站会自动显示原来的占位框，不会出错。
