# LatexPapa — latexpapa.com

Made-to-measure natural latex clothing store. Static site generated by
`site/build.mjs` and deployed to Cloudflare Pages.

## Layout

| Path | What it is |
| --- | --- |
| `site/build.mjs` | The whole static site generator (pages, products, sitemap, robots, llms.txt, admin panel). |
| `site/data/` | Catalogue: `categories.json`, `products.json`, `model-names.json`. |
| `site/assets/` | Brand assets copied verbatim into the build (favicon set, web manifest, hero photo, stylesheet source). |
| `site/worker/` | Cloudflare Pages Functions worker (`_worker.js`) + `_routes.json` for the cart, checkout and /admin/ API. |
| `work/images/webp/` | Processed product photos (one folder per product id). |
| `outputs/site/` | Build output — generated, not committed. |

## Build

```bash
npm install
node site/build.mjs      # writes outputs/site/
```

Preview locally:

```bash
node work/serve.mjs 8788 # http://localhost:8788
```

## Deploy

Deployment is a Cloudflare Pages **direct upload** of `outputs/site`
(this project predates the Git integration used by the three tool sites):

```bash
npx wrangler pages deploy outputs/site --project-name latexpapa --branch main
```

with `CLOUDFLARE_ACCOUNT_ID` and `CLOUDFLARE_API_TOKEN` in the environment.

## SEO / indexing

- `sitemap.xml`, `robots.txt` and `llms.txt` are regenerated by every build.
- An **IndexNow** key file is written to the site root at build time; the key
  itself is in `site/build.mjs` and is submitted to Bing/Yandex after each deploy.
